# Graphix TechHire - React Native Mobile Application

This is the full working cross-platform mobile application for **Graphix TechHire**, built with **React Native (Expo)**, **TypeScript**, and **Axios**.

## 📱 Features

- **Multi-Role Login & Auth**: Student, Recruiter, and Placement Admin tabs with Twilio OTP verification & Google Sign-In.
- **Student Portal**:
  - Live Profile Completeness % meter
  - Application status metrics
  - Open Campus Drives feed with 1-tap application
- **Admin Governance Portal**:
  - Full metrics for 500 Enrolled Indian Students & 50 Tech Companies
  - Searchable student records with status badges
  - Real-time **Approve**, **Block**, and **Unblock** actions
- **Cross-Platform**: Runs on Android, iOS, and Web.

## 🚀 How to Run the Mobile App

1. Navigate to the `mobile` directory:
   ```bash
   cd mobile
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Expo development server:
   ```bash
   npm run start
   ```

4. **Testing Options**:
   - **Android Emulator**: Press `a` in the terminal to launch on Android.
   - **iOS Simulator**: Press `i` in the terminal (macOS).
   - **Physical Device**: Download **Expo Go** from Play Store / App Store and scan the QR code.
   - **Web Version**: Run `npm run web` to test in your web browser!
